# GESTOR DE TAREAS CRUD

Aplicación CRUD de tareas desarrollada con **HTML, CSS y JavaScript Vanilla**, utilizando `fetch()` y `JSON Server` para simular una API REST.

## FUNCIONALIDADES

-  Crear tareas
-  Listar tareas
-  Editar tareas
-  Eliminar tareas
-  Actualización dinámica del DOM
-  Validación de formulario

## TECNOLOGÍAS USADAS

- HTML
- CSS
- JavaScript
- Fetch API
- JSON Server

##  API utilizada

const API_BASE_URL = 'http://localhost:3007/todos';

- Métodos HTTP implementados
Método	Acción
GET	Obtener tareas
POST	Crear tarea
PATCH	Actualizar tarea
DELETE	Eliminar tarea
